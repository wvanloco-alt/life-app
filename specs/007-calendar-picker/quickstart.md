# Quickstart: Calendar Picker

Branch: `007-calendar-picker`. The app is already running at `http://localhost:3000`. Do these steps on This Week, then repeat the day list and Configure on Month. The grids stay as they are.

## 1. Mark a day without a switch

Select today. The list has no switches. Click Running. The row turns into Running's colored bar, the name is white and readable, and the row stays in the same place. Leave the page and come back. It is still marked. Click it again. The row is quiet. If a celebration was still showing, it is gone.

Select a future day. The rows do not mark, and the line about future days is still there.

If a day is marked from Garmin, that row looks marked, does not clear, and still explains why.

## 2. Configure one choice at a time

Open Configure. If nothing is hidden, there is no Hidden heading. Each shown activity has one icon, one color dot, and an empty emoji. The full grids are not on screen.

Click Running's color. Only Running's palette opens. Click Running's icon. The palette closes and the icons open. Pick one. An older running day uses the new icon and color.

Click Climbing's emoji. None is first, then twelve characters. Pick the smile. The slot shows the smile and the list closes.

Hide Tennis. It leaves the day list and appears under Hidden. Show it. It returns in alphabetical order.

## 3. The emoji plays once

With Climbing's emoji empty, mark Climbing. Nothing extra appears.

After the smile is set, mark Climbing. The smile appears once and is gone in under a second. Clear the row. No second smile.

Set the emoji back to None. The next mark plays nothing.

Meditation with the meditating figure plays that figure, not Climbing's smile.

## 4. Add an activity here

In Configure, add " French ". It is stored as "French" and appears on today's list with a default icon, a default color, and no emoji. Change the icon from the row.

Try to add "french" again. The screen says that name is already used, and there is still one French.

There is no delete control on this screen.
